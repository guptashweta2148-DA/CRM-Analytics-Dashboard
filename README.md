# CRM-Analytics-Dashboard
End-to end CRM sales Funnel analysis using Excel, SQL, Power BI and Tableau.

## Project Overview
End-to-end CRM sales funnel analysis for a B2B company, covering 
10,000+ leads and 4,646 opportunities across 8 years of data. 
Built as a group project; personally responsible for Excel dashboards.


## 🛠️ Tools Used
| Excel | Dashboard building, KPI calculation, data cleaning 
| SQL | Data loading, transformation, trend queries |
| Power BI | Interactive executive dashboards |
| Tableau | Revenue and opportunity trend visualizations |

## 📌 Key KPIs Tracked

### Lead Dashboard
- Total Leads: 10,000
- Conversion Rate: 10.33%
- Expected Revenue from Converted Leads: $184M
- Top Lead Source: Direct Sales (33.6%)

### Opportunity Dashboard
- Total Opportunities: 4,646
- Win Rate: 74.7%
- Loss Rate: 41.6%
- Peak Revenue Year: 2020 ($51.6M)
